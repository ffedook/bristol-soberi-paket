# Иконки бустеров 1.3

Созданы встроенным imagegen, без CLI/API-ключа. Оба результата имеют настоящий альфа-канал. После генерации выполнены только техническое уменьшение и WebP-кодирование через Sharp, без перерисовки. Оригинальные PNG сохранены в каноническом архиве дизайна «Бустеры v1.3».

Файлы игры: [Щит](../public/art/booster-shield.webp), [Песочные часы](../public/art/booster-timer.webp). Они используются и в кнопках, и как графический акцент в 3D-сцене.
