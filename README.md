# Собери пакет · Бристоль

Самостоятельная PWA-игра с виртуальными монетами. Нажимай на пакет, увеличивай выигрыш и забирай его до появления белки.

[Открыть игру](https://ffedook.github.io/bristol-soberi-paket/) · [Исходники](https://github.com/ffedook/bristol-soberi-paket)

## Игра

- Стартовый баланс — 1 000 монет.
- Одна бесплатная попытка в день, обновление в 00:00 по Москве.
- Платный вход и единственный отгон белки — по 100 монет.
- 120 шагов; максимальная выплата 2 350 / 5 000 монет.
- Бустеры за монеты в обоих режимах: щит сохраняется до одной кражи; безопасная зона защищает 30 секунд. Покупка сразу включает защиту, каждый тип можно купить до трёх раз за раунд, по одному одновременно. Таймер идёт и при сворачивании игры.
- После отгона неудачный шаг повторяется. Можно сразу забрать восстановленную сумму.
- Случайный исход фиксируется до анимации. Перезагрузка не даёт переиграть кражу.
- Баланс, раунд, история и настройки сохраняются в браузере. Очистка данных удаляет прогресс.
- Реальных денег, платежей, призов и интеграции с программой лояльности нет.

## Запуск и проверка

Node.js 24, pnpm 11:

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm lint
pnpm test
pnpm build
pnpm preview
```

Сборка находится в `dist/`. Все ресурсы локальны, пути относительные: можно размещать в подкаталоге GitHub Pages. Service worker создаётся при сборке и сохраняет целую версию приложения. Обновление активируется после закрытия старых вкладок, чтобы не прервать игру.

На iPhone: Safari → Поделиться → На экран Домой. На Android: Chrome → Установить приложение. Для офлайн-игры дождитесь полной загрузки при первом открытии. Встроенные браузеры могут не поддерживать установку и service worker. На Android используется Vibration API. На iPhone с поддержкой нативного switch (Safari/iOS 18+) реальное касание этого элемента может дать системный тактильный щелчок; сила, доступность и отклик при нескольких пальцах зависят от iOS и настроек устройства. Физический iPhone пока не проверен. Программная вибрация произвольной длительности в Safari недоступна.

## Устройство проекта

- `src/engine.ts` — чистые переходы состояния, расчёты и расчёт дневной попытки.
- `src/balance.json` — все 120 точных выплат и вероятностей исходной таблицы.
- `src/store.ts`, `src/persistence.ts` — сохранение до анимации, Web Locks между вкладками, сессионный резерв при запрете записи.
- `src/App.tsx`, `src/style.css` — интерфейс, анимация появления/кражи, клавиатурная доступность и уменьшенное движение.
- `src/Scene3D.tsx`, `src/characters.ts`, `src/motion.ts` — настоящие объёмные персонажи Three.js, эмоции, подход/захват/побег. Исход определяется движком заранее.
- `src/TapTarget.tsx`, `src/tapGate.ts`, `src/haptics.ts` — независимые касания всех пальцев, блокировка жестов только на игровом поле, нативный отклик по возможности устройства.
- `src/Effects.tsx` — декоративные частицы PixiJS; без WebGL остаётся исходная иллюстрация и игра.
- `docs/release-1.3.md` — актуальные правила и цены бустеров, проверка таймера и анимаций.
- `docs/balance-audit.md` — математика и проверка исходного баланса. Универсальный RTP 90% не заявляется.

Это локальная виртуальная экономика: серверной идентификации и защиты от изменения пользователем собственных данных нет. Современные Safari/Chrome используют Web Locks для последовательных операций между вкладками; в старых браузерах следует играть в одной вкладке.

## Графика

Оригинальные иллюстрации и иконки экспортированы из предоставленного файла Figma «Бристоль», затем оптимизированы в WebP. Добавлены процедурные 3D-модели по мотивам этих иллюстраций с сохранением палитры и образов. На локальном dev-сервере `?scene-lab` открывает проверку эмоций и отдельных моментов кражи; в опубликованной игре этот экран отсутствует. Опубликованы только используемые ресурсы. Товарные знаки и исходные иллюстрации принадлежат соответствующим правообладателям; открытая лицензия на их повторное использование не предоставляется.

Опциональный `scripts/prepare-art.mjs` повторяет оптимизацию исходных PNG из локальной папки `source-art/`. Для обычной сборки эти PNG не нужны: готовые WebP и иконки включены в репозиторий.

## Публикация

`pnpm deploy` запускает проверки, собирает приложение и публикует `dist/` в ветку `gh-pages` текущего репозитория. Нужны авторизованный GitHub CLI (`gh`) и право записи. Скрипт сохраняет историю ветки и не использует force-push. В репозитории включён GitHub Pages с источником `gh-pages`, каталог `/`. Токены в проекте не хранятся.
